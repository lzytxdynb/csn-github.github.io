版本：0.4 / 2026-10-18-ops-1。

这是 GitHub Pages 网页演示，不是已发布的微信小程序，也不是生产会员系统。仅使用虚构资料；不同访客的数据不共享。不要输入真实联系方式、健康资料或密钥。

入口：https://lzytxdynb.github.io/csn-github.github.io/jingluo-fitness/

## 当前功能

会员预约/改约/取消、课卡余额；教练课表、到课核销及课后文字反馈；商家新增课程、发放演示课时、公告和操作流水。新增「课卡与预约规则」支持课卡有效期、到期提示、冻结申请/撤回、商家批准/拒绝及有效期顺延，预约/退改提前量可配置，并检查会员、教练和场地时间重叠。

演示步骤：会员端的团课卡「申请冻结」→切换商家后台「批准」→返回会员端查看「冻结中」及顺延日期。申请不会扣课时；冻结获批后禁止该卡预约。存在冻结时段内的待上课预约会阻止批准，须先处理预约。首次示例有效期90天，默认预约提前30分钟、取消/改约提前120分钟。教练核销开放于课前15分钟至课后48小时。

课卡初次迁移保留原数据，尽可能在当前浏览器保存 jingluo-demo-v5-before-ops1 备份。没有云端备份、真实服务端权限或跨设备同步，不适用于真实经营。

## 三端课表与提醒

日/周/月视图、日期定位、角色和课程筛选、下一节课定位。会员只看自己的演示预约；教练按所选教练排课；商家看全店。网页前台提醒可选提前15/30/60分钟或前一天，按角色保存。系统通知需要主动授权。

网页关闭、休眠、后台限流时不保证按时提醒。Service Worker仅用于本目录通知显示及点击处理，不提供服务端Push。可导出单课或范围ICS，时间按北京时间解释，导出UTC并带VALARM；这是静态快照，改约取消后需手动处理设备日历旧条目，提醒是否生效由设备日历设置决定。
