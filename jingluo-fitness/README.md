# 鲸落健身 · 课表日历与提醒

发布版本：2026-10-15-calendar-2。此目录是 GitHub Pages 公开交互演示，只使用虚构数据，不是正式微信小程序或真实会员系统。

## 三端功能

会员日历只显示演示会员自己的预约，取消后默认隐藏，也可勾选显示已取消记录。教练日历按当前选择的教练显示本人排课，包含尚未有人预约的时段。商家日历展示全部排课，可按教练及私教/团课筛选。三个角色均提供日、周、月视图、日期跳转、当天课程详情、下一节课定位。

提醒设置按会员、每一位教练、商家分别保存在当前浏览器。可选择提前15分钟、30分钟、60分钟和前一天，支持多选。默认仅开启网页内提前30分钟提醒，不主动申请系统通知权限。提醒中心支持测试提醒、标为已读、全部已读、清空已读。

网页每15秒检查当前角色的课程；取消、完成或改约后，旧日程不再触发对应提醒。恢复页面后合并错过的提醒阈值，避免一次弹出多条同课程通知。系统通知需要主动点击并授权；由限定在本目录的 Service Worker 显示，不拦截网络请求，不缓存页面，不做 Push 订阅。

## 日历导出

可导出当前日/周/月范围（遵循当前筛选），也可导出单节课，生成标准 .ics 文件。包含课程名称、地点、起止时间和所选 VALARM 提醒。全部课程时间按北京时间 Asia/Shanghai 解释，导出使用 UTC 时间；旧课程缺少时长时按60分钟演示，新课程可设置15至240分钟。

导出是静态快照，不是订阅，不会自动更新设备日历。改约或取消后需手动处理旧日历条目；再次导入可能重复。是否接受文件里的提醒，由日历应用和设备通知设置决定，请导入后检查。

## 边界

网页关闭、设备休眠或浏览器后台限流时，不保证按时提醒。系统通知功能也不能改变这一限制。需要关闭网页后提醒，应导入设备日历并确认提醒；要做真实微信订阅消息、短信或可靠后台推送，还需后端定时任务、登录身份、通知授权及服务账号。

所有演示资料与设置仅保存在访客自己的浏览器，不同访客之间不共享。页面角色切换仅用于展示，不是生产鉴权。不要输入真实会员联系方式、健康信息或凭据。

## 文件与验证

`calendar-core.js`：日期、角色事件、提醒阈值、iCalendar生成。
`calendar.js`：日历与提醒界面；`calendar.css`：局部样式；`calendar-sw.js`：通知点击处理。
`app.js`：原有应用增加日历数据桥接、北京时间日期和新增课程时长，保留原有浏览器演示数据。

18项纯逻辑测试通过，包括时区、跨年、闰年、角色过滤、取消与改约、提醒去重、ICS时间/转义/UTF-8折行。
21项隔离浏览器页面检查通过，包括三端视图、筛选、设置、预约/取消/改约联动、ICS下载、390px布局。
隔离页面使用原始JS/CSS和内存存储适配器，因为当前执行环境禁止浏览器联网/文件导航。这不是公网点击验收，不验证生产CSP、真实持久化、Service Worker注册或操作系统弹窗；通知拒绝路径使用模拟权限。
